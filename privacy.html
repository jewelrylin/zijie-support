字捷隱私權政策

更新日期：2026 年 10 月 31 日

開發者：chieh-yung lin · 聯絡支援

字捷提供繁體中文鍵盤、離線字庫與聯想字，以及鍵盤外觀設定。這份政策說明資料如何在 App 與鍵盤擴充中使用。

輸入內容與選字記錄

字捷在裝置上處理輸入字碼、中文字候選與聯想字，不將輸入內容上傳到開發者伺服器。鍵盤會在本機儲存字碼與已選候選字的使用次數，用來改善你自己的候選排序；不儲存整段輸入紀錄供開發者讀取。

設定與圖片

輸入法、候選字數量與外觀設定保存在 App 的本機儲存空間。你選取照片或檔案後，App 會將圖片縮小並重新編碼成背景圖，保存在本機；不將圖片上傳給開發者。系統照片與檔案選擇器只將你選取的內容交給 App。

App 與鍵盤透過同一 App Group 共享設定、背景圖與背景解鎖狀態。你在系統中開啟「允許完整取用」後，鍵盤才能讀取這些共享資料。未開啟時，基本離線輸入仍可使用。此權限不代表字捷會上傳輸入內容。

購買與回復購買

背景更換是非消耗型、一次購買的解鎖功能。商品價格、付款、交易驗證及回復購買由 Apple 的 App Store／StoreKit 處理，需要網路連線。字捷使用已驗證的購買狀態來決定是否解鎖，並在本機保存授權快取供鍵盤使用。開發者不會取得你的信用卡號或 Apple 帳號密碼。

Apple 依其政策處理交易資料，請參閱 Apple 隱私權政策。App 重新驗證購買狀態後，已退款或撤銷的解鎖可能不再有效。

追蹤、廣告與分析

字捷沒有第三方廣告或分析 SDK，不使用廣告識別碼，也不進行跨 App 或網站追蹤。離線字庫隨 App 提供，打字不需要向雲端查字。

資料保留與刪除

本機設定、圖片及選字排序資料會保留供 App 使用。刪除 App 與其鍵盤會移除其裝置上的本機資料；購買紀錄由 Apple 管理。若你使用系統備份、裝置移轉或 iCloud 備份，系統可能依你的設定備份 App 資料，此流程由 Apple 作業系統管理，並非字捷自行上傳。

支援聯絡

若你主動聯絡支援，我們會使用你提供的聯絡資料與問題描述協助處理。請不要提供密碼、信用卡號或不必要的私人輸入內容。你可以透過 GitHub Issues 支援頁回報。這是公開討論區，回報內容及 GitHub 個人檔案名稱可能被其他人看見；請勿公開輸入內容、私人照片、密碼、付款資訊或完整購買收據。

支援網站

本支援與隱私網站使用 GitHub Pages 提供服務。GitHub 可能為提供網站及維護安全處理 IP 位址等基本連線紀錄，依 GitHub 隱私權聲明辦理。網站沒有加入第三方廣告或分析程式。這些網站連線資料不會包含鍵盤輸入內容。

政策更新

功能或資料處理方式變更時，我們會更新本頁並修改更新日期。
